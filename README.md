# minitalk

`minitalk`은 UNIX signal을 사용해 별도 프로세스 사이에서 문자열을 전달하는
작은 C 프로젝트다.

## 개발 원칙

- `server`는 자신의 PID를 공개하고 수신한 메시지를 표준 출력에 기록한다.
- `client`는 server PID와 전송할 문자열을 명시적으로 입력받는다.
- 공개 선언은 `include/`, 구현은 `src/` 아래에 둔다.
- compiler warning은 오류로 취급한다.
- 각 단계는 독립적으로 빌드하거나 해당 시점의 검증을 실행할 수 있어야 한다.
- 빌드 산출물과 실행 파일은 Git에 포함하지 않는다.

구현이 진행되면서 구체적인 protocol과 실행 방법을 이 문서에 보완한다.
